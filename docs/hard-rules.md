# 通用硬规则

> 从 CLAUDE.md 拆出。每条规则附 DEV 编号，详细案例见 `error-books/` 对应文件。

## 工具与写入

- **Write 强制分步**（DEV-8）：≤50 行可一次 Write；>50 行先 Write 骨架再 Edit 分段填充，每段 ≤50 行。Write 失败 1 次 → 切 Bash heredoc。禁止同一方式连续失败超过 2 次
- **工具熔断**：同一工具连续失败 2 次同一错误 → 停下换思路，禁止第 3 次盲重试
- **能 Edit 不 Write**（DEV-63）：能用 Edit 局部修改就不用 Write 重写整个文件

## 流程与交互

- **提问即交权**（DEV-53）：同一轮消息禁止"提问 + 执行"并存。提问后唯一允许的动作是等用户回答
- **防丢失**：对话是临时的，文件是持久的（COMMON-1）
- **不做口头承诺**（DEV-76）：教训/流程改进发现当下直接写入对应错题本文件 + 更新 `_index.md`。口头说了但没落盘 = 没做（COMMON-12）
- **禁止脑补**：所有操作必须基于已确认的信息。抓取/搜索失败时不要用猜测的内容代替，必须先确认再写
- **禁止无证据的"根治"**（DEV-85）：禁止在 commit message 中使用"根治/彻底修复/完美解决"等词，除非附带验证证据

## 代码质量

- **LLM 输出防御**（DEV-BUG-16）：接收 LLM 输出的 Pydantic model 必须加 validator/coerce/strip
- **分支矩阵全覆盖**（DEV-BUG-17）：含分支逻辑必须列矩阵逐格实现和测试
- **流式状态机边界检查**（DEV-71）：写/改流式处理逻辑时，必须逐项验证：①操作顺序 ②标签/定界符被 chunk 边界拆开 ③流结束时缓冲区 flush ④空 chunk / 单字符 chunk ⑤所有下游共用同一份 sanitize 函数。缺任一项 = 未完成
- **改前 grep**（DEV-6）：改代码前 grep 全量引用 + grep 同类 pattern 复用
- **重数据不经渲染进程**（DEV-86）：大体积数据禁止经过渲染进程中转，必须在主进程/后端完成采集和传输
- **修复不能为了改动小而降低质量**（DEV-87）：该改架构就改架构，改动大小不是目标，正确性和可维护性才是
- **第三方库先验底层实现**（DEV-88）：采用前必须先查看平台相关源码，确认底层机制和副作用

## 调试与修复

- **两次失败必须搜索**（COMMON-9）：连续猜方案失败两次后停下搜索根因
- **两次补丁失败必须回退换路**（DEV-81）：连续 2 次补丁未解决 → 停下，列出链路副作用，回退到最后正常状态，换完全不同的链路
- **平台 API 先最小复现**（DEV-82）：涉及平台 API 异常行为时，第一步建最小可独立复现的示例
- **3 次 fix commit 强制停下**（DEV-83）：同一功能累计 3 次 fix commit 未解决 = 强制停下 → 回退到第一次 fix 前 → 换技术路径
- **平台能力边界先确认**（DEV-84）：使用平台 API 前：①查官方文档 ②搜 GitHub Issues ③最小复现验证

## Git / Worktree / CR

- **所有改动必须 worktree**（DEV-4）：任何会产生 git diff 的工作都必须在独立 worktree 中进行。唯一例外：worktree 创建命令本身
- **主仓库禁止切分支**（DEV-74）：主仓库目录禁止 `git checkout <branch>` / `git switch`
- **worktree 合回前确认分支**（DEV-67）：合回前必须 `git branch` 确认当前分支是目标分支
- **PR/CR 链接直入 worktree**：用户给 PR 链接要求修时，第一动作必须是门禁声明 + 创建独立 CR worktree
- **CR 修复必须 worktree**：所有 CR 修复在独立 worktree 中进行，流程见 `worktree-workflow.md`
- **CR 闭环**（DEV-68）：①修复+推送 ②回复 PR review comment ③执行出错自动落盘流程 ④输出"CR 闭环完成"标记
- **构建元数据必须取自产物来源**（DEV-64）：禁止用宿主机环境推断

## 网络与抓取

- **网络代理**：所有外网请求走 `http://127.0.0.1:7890`
- **网页抓取降级链**：WebFetch → agent-browser → Scrapling → Playwright
  - **禁止链外工具**（DEV-58）：curl/wget/requests 不得用于抓取网页内容
  - **禁止编造**（DEV-59）：全链路失败 = 没有数据，如实告知用户
